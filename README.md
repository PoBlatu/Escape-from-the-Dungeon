# Подземелье из шести комнат
## Что делает программа
Текстовая мини-RPG. Игрок ходит по карте, находит оружие и зелье здоровья,
сражается с монстрами и ищет выход. Карта открывается постепенно: на экране видны только текущая комната и её соседи, а увиденные комнаты остаются на карте.
 
Обозначения на карте:

| Символ | Значение |
|---|---|
| `@` | игрок |
| `>` | вход |
| `<` | выход |
| `&` | монстр |
| `/` | оружие |
| `+` | зелье здоровья |

Здоровье показывается полоской `[++++--]`. При малом здоровье выводится предупреждение.

## Как запустить
Нужен Python 3.12 или новее, внешние библиотеки не требуются.

```
python main.py
```

На вопрос «Куда идти» вводится направление (регистр и пробелы не важны).
Игра заканчивается победой или смертью.

## Структура
- `new_game`, `neighbors`, `move`, `room_content` — состояние игры и ходы;
- `fight(hp, attack, ...)` — бой, возвращает пару `(оставшееся здоровье, победил ли игрок)`;
- `health_bar(hp, ...)` — возвращает строку с полоской здоровья;
- `render` — рисует карту по координатам комнат и связям;
- коллекции: `dict` (уровень, состояние игры, символы), `list` (связи, сообщения),
  `set` (увиденные комнаты).

## Два сценария проверки
Проверка 1 (обычный сценарий).
Ввод: D, D, D, A, S, S, D, S (маршрут A→B→C→D→C→G→J→K→L).
Ожидание: бой с монстром в C (остаётся 2 HP, предупреждение), зелье в D (6 HP),
оружие в G, победа над монстрами в J и K, затем «Вы дошли до выхода. Победа!».
Результат: так и получилось.

Проверка 2 (граничный сценарий).
Ввод: D, S, S, D, W, W (маршрут A→B→F→I→J→G→C).
Ожидание: после боя в J остаётся 2 HP, в G найдено оружие, в C здоровья
не хватает для боя, и выводится «Вы погибли.».
Результат: так и получилось.
